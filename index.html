💿

⌨️

指令列安裝

為法律工作者設計

從案件管理到法規查詢，整合您日常需要的所有工具。

📄

翻卷宗的時間，還給策略思考

上傳 PDF、DOCX 案件文件，語意搜尋秒級鎖定爭點所在。不必再翻遍整櫃卷宗找一個判決要旨——輸入描述，系統懂得「換句話說」的關鍵內容。

⚖️

一個介面統治法條與實務見解

全國法規資料庫、各級法院裁判書、憲法法庭判決，全部整合在同一個搜尋框。終結十個瀏覽器分頁的噩夢，爭點一查就到位。

🤖

AI 自動比對爭點與適用法條

針對上傳的案件文件，AI 自動分析並推薦可能適用的法律條文，即時驗證條文有效性。降低遺漏重要實務見解的風險。

🔍

釋字/憲判字一站搞定

查詢大法官解釋（釋字）與憲法法庭判決（憲判字），包含判決主文、爭點摘要與引用關係。憲法層級的法源不再難追。

🏠

機密卷宗從不上傳雲端

所有資料與向量索引儲存在你的 Mac 本機。使用自有 API Key 進行 AI 分析，敏感案件資料不會流入第三方伺服器，完全符合律師保密義務。

🔄

資訊室說要排兩週？不用等了

下載 .dmg 雙擊安裝，五分鐘內開工。內建更新機制自動拉取最新版本，資料目錄獨立儲存，更新不會遺失已上傳文件。

選擇適合您的安裝方式

兩種安裝路徑都會在本機建立完整的 Legal Search 環境，包含法規資料庫連線。

💿 圖形介面安裝包

適合不熟悉終端機的法律工作者

  1. 下載 Antu-Legal-Search-macOS.dmg
  2. 開啟 .dmg，將 App 拖曳至「應用程式」資料夾
  3. 首次開啟時，App 會協助您安裝 Docker Desktop
  4. 點擊「啟動服務」，自動完成部署
前往 GitHub Releases 下載
需要：macOS 12+、Docker Desktop（安裝包內建引導）

⌨️ 終端機安裝

適合習慣命令列的進階使用者

# 1. 克隆倉庫
$ git clone https://github.com/antu-tech/law-search-tool.git
$ cd law-search-tool

# 2. 執行安裝腳本
$ bash scripts/install.sh

# 3. 啟動服務
$ bash scripts/start.sh

需要：macOS 12+ 或 Linux、Git、Docker Desktop

常見疑問

律師事務所導入新工具前的三大顧慮，我們直接回答。

「本地安裝會不會很麻煩？我們事務所沒有 MIS。」

提供 macOS 圖形安裝包，流程與安裝 Office 無異；亦提供一鍵終端機腳本供進階用戶。兩種方式都能在五分鐘內完成，無需資訊室排程。

「AI 功能要用我自己的 API Key，會不會很貴或很複雜？」

你完全掌控用量與費率，沒有套裝軟體的綁定授權。基礎搜尋與法源查詢無需 API Key，僅進階 AI 比對才會呼叫，成本透明可控。

「我們已經在用司法院法學資料檢索系統了，為什麼還需要這個？」

官方系統無法搜尋你事務所內部的卷宗與備忘錄，也不支援語意搜尋。Antu 補上「私有文件檢索」與「AI 爭點比對」這兩塊最耗時的缺口。
