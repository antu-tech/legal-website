法律文件檢索，
完全在您的 Mac 上執行。

Antu Legal Search 是一款本地安裝的法律檢索引擎。上傳案件文件，透過語意搜尋快速定位相關法條、裁判書與憲法法庭見解。所有資料儲存在本地，無需擔心隱私外洩。

兩種安裝方式

💿

圖形介面安裝包

下載 .dmg，拖曳安裝。提供啟動、停止、更新按鈕，無需接觸終端機。

⌨️

指令列安裝

一行程式碼複製貼上，透過 Docker Compose 自動部署。

為法律工作者設計

從案件管理到法規查詢，整合您日常需要的所有工具。

📄

案件文件搜尋

上傳 PDF、DOCX 案件文件，使用語意搜尋或關鍵字搜尋快速定位內容。支援混合搜尋模式，結合語意向量與傳統關鍵字的優勢。

⚖️

法條與裁判書查詢

直接連結全國法規資料庫、裁判書系統與憲法法庭資料。輸入爭點，自動搜尋相關法條、判決與釋字/憲判字見解。

🤖

AI 法條比對

針對上傳的案件文件，由 AI 自動分析並推薦可能適用的法律條文，並即時驗證條文有效性。

🔍

憲法法庭判決

查詢大法官解釋（釋字）與憲法法庭判決（憲判字），包含判決主文、爭點與引用關係。

🏠

完全本地執行

所有資料與索引儲存在本機。可搭配自有 API Key 使用 AI 功能，無須將敏感案件資料上傳至第三方雲端。

🔄

一鍵更新

內建更新機制，自動從 GitHub 拉取最新版本並重新部署。資料目錄獨立儲存，更新不會遺失已上傳文件。

選擇適合您的安裝方式

兩種安裝路徑都會在本機建立完整的 Legal Search 環境，包含法規資料庫連線。

💿 圖形介面安裝包

適合不熟悉終端機的法律工作者

  1. 下載 Antu-Legal-Search-macOS.dmg
  2. 開啟 .dmg，將 App 拖曳至「應用程式」資料夾
  3. 首次開啟時，App 會協助您安裝 Docker Desktop
  4. 點擊「啟動服務」，自動完成部署
前往 GitHub Releases 下載
需要：macOS 12+、Docker Desktop（安裝包內建引導）

⌨️ 終端機安裝

適合習慣命令列的進階使用者

# 1. 克隆倉庫
$ git clone https://github.com/antu-tech/law-search-tool.git
$ cd law-search-tool

# 2. 執行安裝腳本
$ bash scripts/install.sh

# 3. 啟動服務
$ bash scripts/start.sh
查看完整安裝指南
需要：macOS 12+ 或 Linux、Git、Docker Desktop
