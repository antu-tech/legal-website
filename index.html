常見疑問

律師事務所導入新工具前的常見問題，我們直接回答

01

開啟 App 時顯示「無法驗證是否包含惡意軟體」？

這是 macOS Gatekeeper 的正常提示，因為本專案為開源軟體，尚未申請 Apple 開發者簽章。請在「系統設定」→「隱私權與安全性」中向下捲動，點擊「仍要開啟」即可。原始碼公開於 GitHub，可自由稽核。

02

本地安裝會不會很麻煩？我們事務所沒有 MIS。

提供 macOS 圖形安裝包，流程與安裝 Office 無異；亦提供一鍵終端機腳本供進階用戶。兩種方式都能在五分鐘內完成，無需資訊室排程。

03

AI 功能要用我自己的 API Key，會不會很貴或很複雜？

你完全掌控用量與費率，沒有套裝軟體的綁定授權。基礎搜尋與法源查詢無需 API Key，僅進階 AI 比對才會呼叫，成本透明可控。

04

我們已經在用司法院法學資料檢索系統了，為什麼還需要這個？

官方系統無法搜尋你事務所內部的卷宗與備忘錄，也不支援語意搜尋。Antu 補上「私有文件檢索」與「AI 爭點比對」這兩塊最耗時的缺口。
